Concord

A deterministic supervisor for AI proposals and recorded effects. A model can propose work. Only the supervisor can authorize and schedule it. Every result becomes evidence; replay consumes the evidence without reexecuting tools.

Implementation slices

Decisions in effect

Use the existing Node ESM scaffold with built-in modules. Execute the DAG serially in stable topological order. Require an exact request hash for write, network and process effects. Keep optional upstream runtimes separately installed. Use recorded replay for reproducibility; do not claim deterministic live AI.

Limits to preserve

Hashes detect corruption relative to a trusted root; they are not signatures. Registered JavaScript adapters are trusted code. A process wrapper is not an operating system sandbox. An interrupted external operation may have happened; automatic resume cannot safely infer otherwise.
